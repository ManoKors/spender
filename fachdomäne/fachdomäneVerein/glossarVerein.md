# Glossar: Zuwendungsbestätigung für Geldzuwendungen an Vereine (Muster 034122)

Dieses Glossar erklärt ausschließlich die Begriffe des amtlichen Formulars **034122 „Bestätigung über Geldzuwendung / steuerbegünstigte Einrichtung / Verein" (Fassung 2013)**. Es gilt vorerst für die Vereinsebene (e. V.) und nur für **Geldzuwendungen**. Sachspenden, Sammelbestätigungen und Körperschaften des öffentlichen Rechts (z. B. Universitäten, Muster 034120) sind bewusst nicht enthalten.

Es folgt den Prinzipien aus dem Workshop:

- **Erweiterte Form:** 3 Spalten (*Geschäftsobjekt*, *Attribut*, *Definition*). In der ersten Zeile steht das Geschäftsobjekt, darunter versetzt seine Attribute.
- **Singular-Konvention:** Alle Geschäftsobjekte stehen im Singular.
- **Rein fachlich:** Keine Datentypen, keine Datenbankbegriffe.
- **Trennung von Objekten und Regeln:** Rechtliche Voraussetzungen (z. B. Gegenleistungsfreiheit) sind Regeln und keine Attribute.
- **Verständlich:** Die Definitionen sind in Alltagssprache geschrieben. Fachbegriffe aus dem Steuerrecht werden in Abschnitt 4 erklärt.

## 1. Geschäftsobjekte und Attribute (so wie sie auf dem Formular stehen)

| Geschäftsobjekt | Attribut | Definition |
|---|---|---|
| **Zuwendungsbestätigung** | | Das amtliche Formular, umgangssprachlich „Spendenquittung". Der Verein bescheinigt damit, dass jemand ihm Geld zugewendet hat. Der Zuwendende legt es dem Finanzamt vor, um die Zahlung steuerlich abzusetzen. Diese Fassung heißt „Bestätigung über Geldzuwendungen/Mitgliedsbeitrag" und gilt für steuerbegünstigte Vereine. |
| | Betrag in Buchstaben | Der Betrag ausgeschrieben, z. B. „einhundertfünfzig Euro". Er schützt davor, dass die Zahl nachträglich verändert wird. |
| | Bestätigter Zweck | Der Zweck, für den der Verein das Geld laut Bestätigung ausschließlich verwendet (siehe *Steuerbegünstigter Zweck*). |
| | Bestätigung „kein ausgeschlossener Mitgliedsbeitrag" | Zusatzsatz, den nur bestimmte Vereine übernehmen (siehe Regel 5). |
| | Ausstellungsort | Ort, an dem die Bestätigung ausgestellt und unterschrieben wird. |
| | Ausstellungsdatum | Tag, an dem die Bestätigung ausgestellt wird. Er entscheidet mit darüber, ob der Bescheid des Finanzamts noch aktuell genug ist (Regel 2). |
| | Unterschrift | Unterschrift einer für den Verein vertretungsberechtigten Person, z. B. des Vorstands. |
| | Muster | Nummer und Jahr der amtlichen Vorlage (hier 034122, 2013). Sie steht am Fuß des Formulars und zeigt, welche Fassung verwendet wurde. |
| **Zuwendender** (Synonym: Spender) | | Person oder Firma, die dem Verein das Geld gibt. Der Begriff „Zuwendender" steht so auf dem Formular. |
| | Name | Vollständiger Name der Person bzw. Bezeichnung der Firma. |
| | Anschrift | Wohnort bzw. Firmensitz. Sie wird auf der Bestätigung abgedruckt. |
| **Zuwendungsempfänger** (Synonym: Aussteller) | | Der steuerbegünstigte Verein, der das Geld erhält und die Bestätigung ausstellt. „Steuerbegünstigt" heißt: Das Finanzamt hat anerkannt, dass er gemeinnützige, mildtätige oder kirchliche Ziele verfolgt. Auf dem Formular steht er oben als „Aussteller" und bei der Unterschrift als „Zuwendungsempfänger". Gemeint ist derselbe Verein. |
| | Bezeichnung | Name des Vereins, z. B. „Förderverein Musterstadt e. V.". |
| | Anschrift | Sitz des Vereins. |
| **Geldzuwendung** | | Zahlung von Geld an den Verein, für die der Zahlende nichts Gleichwertiges zurückbekommt. Das Formular gilt nur für Geld. Für Sachspenden gibt es ein anderes amtliches Muster. |
| | Zuwendungsart | Spende (freiwillig gegeben) oder Mitgliedsbeitrag (aus der Mitgliedschaft geschuldet). Der Verein streicht auf dem Formular, was nicht passt. |
| | Betrag | Die gezahlte Summe in Euro, auf dem Formular „in Ziffern", z. B. 150,00 €. |
| | Tag der Zuwendung | Das Datum, an dem das Geld gezahlt wurde. |
| | Verzicht auf Erstattung von Aufwendungen | Ja/Nein-Angabe. „Ja" heißt: Es wurde nicht gezahlt, sondern auf einen Anspruch gegen den Verein verzichtet (siehe Regel 4). Bei einer normalen Zahlung steht „Nein". |
| **Steuerbegünstigter Zweck** | | Ein Ziel, das der Verein laut Satzung verfolgt und das das Finanzamt als spendenwürdig anerkennt, z. B. Förderung von Wissenschaft und Forschung, Bildung oder Jugendhilfe. Er erscheint auf dem Formular dreimal (Mittelverwendung, Befreiung laut Bescheid, Satzung) und muss jeweils zu Bescheid bzw. Satzung passen. |
| | Wortlaut des Zwecks | Der Zweck, so formuliert wie in Bescheid bzw. Satzung. |
| **Gemeinnützigkeitsbescheid** || Fasst Freistellungsbescheid und Festellungsbescheid als Solche zusammen, verstanden wird also die Steuerbegünstigung vom Finanzsamt unabhängig vom Ausgestellten Schreiben|| |
| **Freistellungsbescheid** (bzw. Anlage zum Körperschaftsteuerbescheid) | | Schreiben des Finanzamts, das nach Prüfung der Steuererklärung bestätigt: Der Verein ist für die geprüften Jahre gemeinnützig und zahlt deshalb keine Körperschaft- und Gewerbesteuer. Er ist der Nachweis, dass der Verein Bestätigungen ausstellen darf. Muss der Verein trotzdem Körperschaftsteuer zahlen (z. B. wegen steuerpflichtiger Einnahmen), steht dieselbe Aussage in der „Anlage zum Körperschaftsteuerbescheid". |
| | Finanzamt | Das für den Verein zuständige Finanzamt, das den Bescheid erlassen hat. |
| | Steuernummer | Nummer, unter der das Finanzamt den Verein führt (nicht die Vereinsregisternummer). |
| | Datum des Bescheids | Tag, an dem der Bescheid ausgestellt wurde. Er ist maßgeblich für die Gültigkeitsdauer (Regel 2). |
| | Letzter Veranlagungszeitraum | Das letzte Steuerjahr, für das die Befreiung festgestellt wurde, z. B. 2023. |
| | Zweck laut Bescheid | Der Zweck, wegen dessen das Finanzamt die Befreiung ausgesprochen hat. |
| **Feststellungsbescheid** (nach § 60a AO) | | Schreiben des Finanzamts, das feststellt, dass die Satzung des Vereins alle Anforderungen der Gemeinnützigkeit erfüllt. Typisch ist das für neue Vereine, die noch keinen Freistellungsbescheid haben, oder nach einer Satzungsänderung. Welcher der beiden Bescheide auf der Bestätigung steht, hängt davon ab, was der Verein hat. |
| | Finanzamt | Das Finanzamt, das die Feststellung getroffen hat. |
| | Steuernummer | Steuernummer des Vereins bei diesem Finanzamt. |
| | Datum des Bescheids | Tag der Feststellung. Maßgeblich für die Gültigkeitsdauer (Regel 2). |
| | Zweck laut Satzung | Der Zweck, den der Verein nach seiner Satzung fördert. |

## 2. Voraussetzung vor der Ausstellung (nicht Teil des Formulars)

Dieses Objekt steht **nicht auf dem Formular**. Das amtliche Muster verlangt keine gesonderte Erklärung des Zuwendenden. Der Verein holt sie als interne Voraussetzung ein, um die Unentgeltlichkeit der Zuwendung zu belegen, denn er haftet für unrichtige Bestätigungen (Regel 7).

| Geschäftsobjekt | Attribut | Definition |
|---|---|---|
| **Gegenleistungsverzichtserklärung** | | Erklärung des Zuwendenden, dass er für seine Zahlung keine Gegenleistung erhält und auch keine erwartet (keine Ware, keine Dienstleistung, keine Werbeleistung). Sie ist Voraussetzung dafür, dass der Verein die Zuwendungsbestätigung ausstellen darf (OCL 7). |
| | Erklärender | Der Zuwendende, der die Erklärung abgibt. |
| | Erklärungsdatum | Tag der Erklärung. Sie muss vor der Erfassung der Spendenabsicht bzw. der Ausstellung der Bestätigung vorliegen. |
| | Betroffene Geldzuwendung | Die Zahlung bzw. Spendenabsicht, auf die sich die Erklärung bezieht. |
| **Spendenabsicht** (Synonym: Pledge) | | Verbindliches Spendeversprechen, das ein Zuwendender im White-Label-Wizard vorab registriert. Sie verknüpft Spender, Zweck, Betrag und Verzichtserklärung mit einem eindeutigen Referenzcode. |
| | Referenzcode | Eindeutige Kennung (z. B. `SP-2026-4821`), die im Verwendungszweck der Überweisung angegeben wird, um Geldeingänge automatisiert zuzuordnen. |
| | Status | Status im Lebenszyklus: `ANGEKUENDIGT` (Wizard abgeschlossen), `EINGEGANGEN` (Überweisung gebucht) oder `ABGELAUFEN`. |
| | GiroCode-Payload | Normierter Zeichensatz nach EPC069-08 für den SEPA-QR-Code. |
| **EPC-GiroCode** | | Standardisierter QR-Code für den europäischen Zahlungsverkehr (European Payments Council Quick Response Code). Ermöglicht das fehlerfreie Scannen aller Zahlungsdaten (Empfänger, IBAN, BIC, Betrag, Referenzcode) direkt in Banking-Apps. |
| **White-Label-Konfiguration** | | Mandantenspezifische Darstellungseinstellungen, mit denen der Spenden-Wizard nahtlos im Corporate Design des jeweiligen Vereins erscheint. |
| | Slug | Eindeutiger URL-Pfadbestandteil des Vereins (z. B. `katzenschutz-ms`). |
| | Primärfarbe | CI-Hauptfarbe für Buttons, Icons und Hervorhebungen im Wizard. |
| | Wizard-Titel / Dankestext | Individuelle Ansprache und Bestätigungsmeldung für die Spender. |

## 3. Fachliche Regeln

| Nr. | Regel | Einfach erklärt |
|---|---|---|
| 1 | **Gegenleistungsfreiheit** | Der Zuwendende darf für sein Geld nichts Gleichwertiges bekommen. Sonst ist es keine Spende, sondern z. B. Sponsoring, und der Verein darf keine Zuwendungsbestätigung ausstellen. Nachgewiesen wird das über die *Gegenleistungsverzichtserklärung* (Abschnitt 2). |
| 2 | **Gültigkeitsdauer des Bescheids** (§ 63 Abs. 5 AO) | Der Freistellungsbescheid darf höchstens 5 Jahre alt sein, der Feststellungsbescheid höchstens 3 Jahre. Ist der Bescheid älter, erkennt das Finanzamt die Bestätigung nicht an. Der Hinweis steht unten auf dem Formular. |
| 3 | **Entweder-oder der Bescheide** | Der Verein gibt den Bescheid an, den er hat: entweder Freistellungsbescheid (bzw. Anlage zum Körperschaftsteuerbescheid) oder Feststellungsbescheid. |
| 4 | **Verzicht auf Erstattung von Aufwendungen** (Aufwandsspende) | Der Zuwendende hätte vom Verein Geld bekommen, z. B. Fahrtkosten, und verzichtet darauf. Das zählt wie eine Spende. In der Regel muss der Anspruch vorher vereinbart gewesen sein, der Verzicht zeitnah erfolgen und der Verein zahlungsfähig sein. |
| 5 | **Abzugsausschluss bei Mitgliedsbeiträgen** | Bei Vereinen mit bestimmten Zwecken (u. a. Sport, Freizeitgestaltung, Brauchtum) sind Mitgliedsbeiträge steuerlich nicht abziehbar, Spenden schon. Diese Vereine nehmen den Zusatzsatz in die Bestätigung auf, dass es sich nicht um einen ausgeschlossenen Mitgliedsbeitrag handelt. |
| 6 | **Betrag stimmig** | Betrag in Ziffern und in Buchstaben müssen übereinstimmen. |
| 7 | **Aussteller- und Veranlasserhaftung** | Der Verein haftet für die entgangene Steuer, wenn er vorsätzlich oder grob fahrlässig eine unrichtige Bestätigung ausstellt oder veranlasst, dass das Geld nicht für den bestätigten Zweck verwendet wird. Der Hinweis steht auf dem Formular. |
| 8 | **Amtliches Muster** | Das Muster ist verbindlich. Der Verein stellt die Bestätigung selbst nach dem Muster her und übernimmt nur die Angaben, die im Einzelfall zutreffen. Sie darf eine DIN-A4-Seite nicht überschreiten und keine Danksagung und keine Werbung enthalten. |

## 4. Rechtsbegriffe zum Nachschlagen

| Begriff | Einfach erklärt |
|---|---|
| § 10b EStG | Paragraf im Einkommensteuergesetz zum Spendenabzug: Wer darf welche Spenden von der Steuer absetzen? |
| § 5 Abs. 1 Nr. 9 KStG | Vorschrift, nach der Organisationen mit ausschließlich gemeinnützigen, mildtätigen oder kirchlichen Zwecken keine Körperschaftsteuer zahlen. Sie legt fest, für welche Empfänger dieses Formular gilt. |
| Körperschaft, Personenvereinigung, Vermögensmasse | Sammelbegriffe der Steuergesetze für Organisationen wie Vereine, Gesellschaften und Stiftungen. |
| Körperschaftsteuer | „Einkommensteuer" für Organisationen. |
| Gewerbesteuer, § 3 Nr. 6 GewStG | Steuer auf gewerbliche Tätigkeit, die die Gemeinden erheben. § 3 Nr. 6 befreit gemeinnützige Organisationen davon. |
| Veranlagungszeitraum | Das Steuerjahr, für das eine Steuer festgesetzt oder geprüft wird. |
| Satzung | Die Grundregeln des Vereins. Sie legt unter anderem seine Zwecke fest. |
| §§ 51, 59, 60, 61 AO | Regeln der Abgabenordnung zur Gemeinnützigkeit: allgemeine Voraussetzungen (§ 51), Satzung und tatsächliche Geschäftsführung müssen passen (§ 59), Anforderungen an die Satzung (§ 60), Vermögensbindung bei Auflösung (§ 61). |
| § 60a AO | Regelt, dass das Finanzamt die Satzung vorab prüft und gesondert feststellt (Feststellungsbescheid). |
| Gemeinnützig, mildtätig, kirchlich | Die drei Zweckgruppen: der Allgemeinheit nützen, Hilfsbedürftigen helfen, Religionsgemeinschaften fördern. |
| Sachspende | Spende von Gegenständen statt Geld. Dafür gilt ein anderes Muster (nicht Teil dieses Glossars). |
| § 10b Abs. 4 EStG, § 9 Abs. 3 KStG, § 9 Nr. 5 GewStG | Dieselbe Haftungsregel für die drei Steuerarten (Einkommen-, Körperschaft-, Gewerbesteuer), bei denen Spender die Zuwendung geltend machen. |

## 5. Offene Punkte zum Abgleich mit den Originalquellen

1. **Wortlaut der Frist (Regel 2):** Das vorliegende PDF sagt „seit Ausstellung des Bescheides". Andere Fassungen des Hinweises, die wir gesehen haben, beziehen die Frist auf die Ausstellung der Bestätigung. Fachlich sinnvoll ist der Vergleich des Bescheiddatums mit dem Ausstellungsdatum der Bestätigung. Mit dem offiziellen BMF-Muster abgleichen.
2. **Mitgliedsbeiträge (Regel 5):** Welche Zwecke vom Abzugsausschluss betroffen sind, steht in § 10b EStG in Verbindung mit § 52 AO. Die Aufzählung hier ist nur ein Hinweis.
3. **Verzicht auf Erstattung (Regel 4):** Die genauen Voraussetzungen (Zeitpunkt der Anspruchsvereinbarung, zeitnaher Verzicht, Zahlungsfähigkeit) in § 10b EStG und den Einkommensteuer-Richtlinien nachlesen, bevor sie als Prüfregeln umgesetzt werden.
4. **Aktualität und Verfahren:** Die Fassung 2013 ist die Grundlage dieses Glossars. Vor dem Produktivbetrieb prüfen, ob eine neuere Fassung gilt und welche Regeln für maschinell erstellte Bestätigungen gelten (z. B. Anzeige beim Finanzamt, Form der Unterschrift).
